# 极光剪映 LuminaCut

Windows 专业视频剪辑软件：WPF(.NET 8) + 原生 C++ 媒体内核(FFmpeg / D3D11VA) + D3D11/HLSL GPU 合成 + ONNX/DirectML 本地 AI。

## 下载
进入 **[Releases](../../releases)** 下载最新 `LuminaCut-Setup-<版本>.exe`，双击安装即可（Windows 10 / 11 x64，已捆绑 VC++ 运行时）。
完整性校验：每个版本随附 `LuminaCut-Setup-<版本>.exe.sha256`。

## 主要能力
- **剪辑**：视频 / 音频 / 字幕多轨时间线，帧精确修剪、Roll / Slip / Slide、波纹修剪、关键帧动画、嵌套片段、多机位、代理(Proxy)工作流、渲染缓存
- **调色**：一级调色、曲线、3D LUT、多点 HSL 限定器节点链、色轮、示波器(波形 / 矢量 / 直方图)、色彩管理(ACES)、HDR
- **音频**：音频主时钟低延迟回放、EQ / 压缩 / 响度归一化、混响、自动闪避、5.1 环绕声、AI 人声分离与降噪
- **AI（本地推理）**：智能字幕(ASR)、智能配音(TTS)、人像抠像、超分高清、光流补帧、运动防抖、场景检测
- **导出**：H.264 / HEVC / AV1 硬编与软编兜底、MP4 / MKV / MOV、CRF 恒定质量、纯音频、GIF、批量与后台导出队列
